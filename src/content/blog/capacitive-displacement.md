微位移测量不是简单地“把尺子做得更细”。当位移进入微米尺度，机械间隙、边缘电场、温漂、装调误差与采集噪声会同时进入结果。差动式电容结构的价值，在于它既提高灵敏度，也能在一定程度上抑制共模扰动。

## 从平行板模型开始

理想平行板电容满足

$$
C = \frac{\varepsilon A}{d}.
$$

令可动极板相对中心位置发生位移 $x$，两侧初始间距均为 $d_0$，则

$$
C_1 = \frac{\varepsilon A}{d_0-x},\qquad
C_2 = \frac{\varepsilon A}{d_0+x}.
$$

差动输出为

$$
\Delta C = C_1-C_2
= \frac{2\varepsilon A x}{d_0^2-x^2}.
$$

当 $|x|\ll d_0$ 时，可以取一阶近似：

$$
\Delta C \approx \frac{2\varepsilon A}{d_0^2}x.
$$

这一结果说明中心附近具有良好的线性关系。但实验真正困难的部分，恰好发生在“近似不再足够好”的地方。

## 误差并不只是一串随机数

实际装置中，以下因素会改变曲线形状：

1. 极板不完全平行，导致有效间距随位置变化；
2. 边缘电场使有效面积不再等于几何重叠面积；
3. 机械平台存在回程差与微小迟滞；
4. 测量电路的零点与增益随温度漂移；
5. 采样信号中同时存在工频干扰和高频噪声。

因此，数据处理不能只报告一个 $R^2$。更重要的是分别观察重复性、回程差、残差的结构，以及模型在标定区间之外是否仍然稳定。

## 为什么引入机器学习

解析模型提供物理可解释性，但难以完整描述装调误差造成的高阶非线性。数据驱动模型可以学习从多通道观测量到位移的映射，用作标定曲线的补充。

一个简化的处理流程如下：

```python
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.ensemble import RandomForestRegressor

model = make_pipeline(
    StandardScaler(),
    RandomForestRegressor(
        n_estimators=300,
        max_depth=8,
        random_state=42,
    ),
)
model.fit(X_train, y_train)
prediction = model.predict(X_test)
```

这里最重要的不是换一个更复杂的算法，而是避免数据泄漏：同一次连续扫描中相邻采样点高度相关，随机打散后划分训练集与测试集，可能得到过于乐观的误差。更可靠的做法是按扫描轮次、时间段或实验批次分组验证。

## 如何理解“约 5 μm”

位移分辨不能只由最小刻度宣布。它至少应同时满足：输入变化能够引起可区分的输出、重复测量的分布具有足够分离度，并且整个测量链在相应时间尺度上保持稳定。

因此，“约 5 μm 量级”更接近对完整系统能力的描述：它属于特定量程、采样方式、滤波参数和环境条件，而不是脱离实验条件的常数。

这次工作给我的最大提醒是：机器学习可以改善标定，却不能替代对装置的理解。只有先知道误差可能从哪里进入，数据模型的提升才具有物理意义。
